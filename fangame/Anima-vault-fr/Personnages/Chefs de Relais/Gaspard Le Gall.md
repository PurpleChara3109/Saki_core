# Gaspard Le Gall

Relais 3, type Eau, 52 ans. Ancien marin devenu showman, il dirige un Relais portuaire.

- **Traits** : théâtral, il se présente en trois minutes de monologue, et il a le mal de mer.
- **Position** : l'honnête loyaliste. Il croit que le système protège les gens.
- **Combat** : enseigne les formes et les signatures, avec une eau qui prend la forme de son contenant, en écho à Mew.
- **Rôle dans l'intrigue** : convoie les stocks distillés.
- **S'il bascule** : il reste loyal, le joueur doit intercepter son convoi.

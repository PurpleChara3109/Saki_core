# Lumeris Consortium

- **Rôle** : entreprise énergétique, fabrique les Cellules et les Relais.
- **Position sur l'Anima** : exploiter.
- **Voie de maîtrise** : Techno (voir [[Voies de maitrise|Voies de maîtrise]]).
- **Loi mise à l'épreuve** : Densité (Régénération près des Veines, gestion du Flux).
- **Secret** : la [[Distillation]] en deux temps. La conversion (publique, dite non létale) use les Pokémon ; la distillation dissout les convertisseurs saturés pour des Cellules premium. Le joueur le découvre peu avant le Relais 8.
- Laisse les [[Les Effaces|Effacés]] tranquilles. Sa Source est [[Ysolde Verdier]].
- Les huit Chefs de Relais y sont affiliés (voir [[Veines et Relais]]).

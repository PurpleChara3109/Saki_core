# Type Aria

Nouveau type (le 19e), réservé aux Pokémon qui ressentent l'Anima plus que les autres. C'est un type normal dans la région de Ryven.

- **Faiblesse** : Poison.
- **Résistances** : Ténèbres, Spectre.
- **Super efficace contre** : Combat, Ténèbres.
- **Immunité** : attaques de statut. Les actions de forme Lien (renouer un lien, Voile d'Hector) ne comptent pas comme statut pour cette immunité (règle à confirmer).
- **Répartition** : environ un tiers des espèces du jeu (environ 33 sur 100), dont 5 dans la démo (voir [[Pokemon de depart|Pokémon de départ]]).
- Plante/Aria subit ×4 du Poison : voulu, compensé par l'immunité aux statuts.
- Chaque Aria réagit visiblement à l'Anima (halo près d'une Veine, réaction avant un combat).

Voir [[Cinq lois]], [[Lexique]].

## Mode d'emploi rapide
1. Ouvre ce dossier comme vault (« Open folder as vault »).
2. Active le plugin de base **Templates** (Settings > Core plugins) et pointe-le sur le dossier `Templates`.
3. Ouvre la **Graph view** pour voir les liens entre notes.
4. Chaque nouvelle fiche part d'un modèle : `Templates/Personnage` ou `Templates/Faction`.

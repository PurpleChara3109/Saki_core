# Le Lien

Le Lien est la relation d'Anima entre un dresseur et son Pokémon. Il permet d'injecter de l'Anima (rang Conducteur) et se mesure en quatre paliers.

| Palier | Idée |
| --- | --- |
| Réticent | Le Pokémon obéit mal, la Poussée est risquée. |
| Fiable | Base solide. |
| Uni | Le Pokémon répond avant l'ordre. |
| Accord parfait | Fusion des Anima ; réservé aux liens les plus forts. |

Les avantages chiffrés et les variations sont dans le document technique. Voir [[Cohesion|Cohésion]], [[Combat (resume)|Combat (résumé)]], [[Effacement]] (un Effacé est reconnu ou non par son Pokémon).
